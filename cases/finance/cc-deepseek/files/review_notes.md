# 独立复核说明（review_notes.md）

本文件从题设输入数字**独立重算**，不复用前文结论。每项标注为：
- ✅ **已满足的政策约束** —— 有政策依据且本家庭符合
- 🔷 **测算假设** —— 题设给定或本报告设定的计算口径，非政策
- ⚠️ **仍须确认** —— 须经银行/公积金中心/教育部门确认

## 一、复核方法与工具

全部数值由独立 Python 脚本重算，采用**逐月摊销循环**（非公式近似）：

```
余额 = 计息余额；月利率 = 年利率 / 12
每月：利息 = 余额 × 月利率；本金 = min(月供 − 利息, 余额)；余额 −= 本金
```

**关键身份式全部通过**：

| 身份式 | 左 | 右 | 通过 |
|---|---|---|---|
| 首付 + 贷款 = 房价 | 246,800 + 993,200 = 1,240,000 | 1,240,000 | ✅ |
| 贷款 − 一次还本 = 计息余额 | 993,200 − 589,000 = 404,200 | 404,200 | ✅ |
| 可用现金 − 首付 − 税费 = 现金储备 | 284,000 − 246,800 − 37,200 = 0 | 0 | ✅ |
| 公积金余额 − 留存 = 一次还本 | 596,000 − 7,000 = 589,000 | 589,000 | ✅ |
| 月供 = 公积金月冲 + 现金结余 | 7,000 + 3,000 = 10,000 | 10,000 | ✅ |
| 各期还款之和 = 计息余额 + 总利息 | 426,646.65 = 404,200 + 22,446.65 | ✅ | ✅ |

**交叉验证等待月数**：2025-12-31 → 2028-04-30 = 28 个月 ✅

**分类**：
- 🔷 **测算假设**：等待 28 个月、2028-04 交易，系题设给定的**保守规划截止假设**，**不是 2028 年已公布的招生政策**。
- ✅ **已满足的政策约束**：转学须在暑假进行且毕业年级不转学（无锡市教育局 Q34）；"三一致"入学要求且无落户年限要求（Q20/Q21）。
- ⚠️ **仍须确认**：2028 年施教区划分、回户籍地小升初能否精确落位天一实验学校（属**统筹安排**）。

### 2.2 资金来源

**重算**（四账分开，公积金不抵首付）：

| 账目 | 计算 | 金额（元） |
|---|---|---:|
| 现有现金 | 题设 | 200,000 |
| 现金结余累积 | 3,000 × 28 | 84,000 |
| **购房时可用现金** | | **284,000** |
| 现有公积金 | 题设 | 400,000 |
| 公积金缴存累积 | 7,000 × 28 | 196,000 |
| **购房时可用公积金** | | **596,000** |
| 首付 15% | 1,240,000 × 15% | 186,000 |
| 契税 3% | 1,240,000 × 3% | 37,200 |
| **现金支出合计** | 186,000 + 37,200 | **223,200** |
| 剩余现金 | 284,000 − 223,200 | **60,800** |

**分类**：
- ✅ **已满足的政策约束**：公积金账户资金**只能用于还贷提取**，不能直接支付首付（无锡市公积金中心《偿还住房贷款本息提取住房公积金须知》）；本方案首付与税费**全部由现金承担**，未混用。
- 🔷 **测算假设**：现金月结余 3,000 元、公积金月缴存 7,000 元分别累积且不挪用；契税按 3%。
- ⚠️ **仍须确认**：契税实际适用税率（若适用 1%，可省 24,800 元）；家庭第 4 套住房**能否获得商业贷款**及其最低首付比例——**这是本方案最大的未决项**。

### 2.3 利率

**重算**：题设商贷 3.000%/年，公积金 2.500%/年。

**检索核对**（无锡市公积金中心《关于下调个人住房公积金贷款利率的通知》，2025-05-08 起执行）：

| 类型 | >5 年利率 | 与商贷 3.000% 比较 |
|---|---:|---|
| 首套 | 2.600% | 低于商贷 |
| **第二套** | **不低于 3.075%** | **高于商贷** |
| 商业贷款（题设） | 3.000% | — |

**重算结论**：本家庭已有 3 套住房，拟购为第 4 套。按无锡市公积金中心《购房贷款须知》，**"停止向购买第三套及以上住房的缴存职工家庭发放住房公积金贷款"**，公积金贷款**资格不成立**；即便按二套档评估，**3.075% > 3.000%**，也无利率优势。**两条独立理由共同排除公积金贷款路径**。

**采用利率**：**3.000%/年**（商业贷款）。

**分类**：
- ✅ **已满足的政策约束**：公积金贷款发放对象限于首套/第二套自住住房家庭。
- 🔷 **测算假设**：商贷利率固定 3.000%/年，全期不变（题设）；未考虑 LPR 浮动。
- ⚠️ **仍须确认**：实际商贷定价（以届时 LPR 及各行加成为准）；题设"公积金 2.500%"与检索所得 2.600%/3.075% 不一致，本报告**采用检索所得做资格与利率判断**，采用题设利率仅作对照。

### 2.4 月供上限

**重算**：题设每月偿债能力 **10,000 元（含月冲）**。

**资金来源核对**：

| 来源 | 金额 |
|---|---:|
| 公积金月缴存（月冲） | 7,000 |
| 现金月结余 | 3,000 |
| **合计** | **10,000** |

**关键复核**：题设明确"**不能与前期已累积余额重复计算**"。本方案已严格遵守：
- 前期累积（现金 84,000 + 公积金 196,000）**只用于**首付、税费、一次性还本；
- 月供 10,000 元**完全由未来现金流**（公积金 7,000 + 现金 3,000）承担；
- 两套资金**无重叠**。✅

**分类**：
- ✅ **已满足的政策约束**：公积金逐月还贷（月冲）须保留"最近一个月月实缴额的 **6 倍**"（《住房贷款委托还贷须知》）。
- 🔷 **测算假设**：月供固定 10,000 元且贴满上限；月冲 7,000 元足额可用。
- ⚠️ **仍须确认**：银行对"月还款额 ≤（借款本人月收入+配偶月收入）× 60%"的**收入审核**（无锡市公积金中心《购房贷款须知》所列额度约束之一）；本家庭实际收入证明是否满足 10,000 元月供须经银行核定。

### 2.5 还清期限

**重算**（逐月摊销，月供 10,000 元，年利率 3.000%）：

| 项目 | 数值 |

| 计息余额 | 404,200 元 |

**对照核验（一次性还本的杠杆效应）**：

| 方案 | 计息余额 | 结清月数 | 总利息 |
|---|---:|---:|---:|
| 使用公积金一次还本 | 404,200 | **43** | **22,447** |

| **差额** | | **少 72 个月** | **少 127,454** |

| 项目 | 基准方案 | 稳健方案 |

| 首付 | 246,800 | 186,000 |

**两个储备假设不可合并**：60,800 元既是基准方案的剩余现金，也是稳健方案的留存目标——同一笔钱用于加付首付就不能留存，反之亦然。**不得混为同一最优结果。** ✅

**法定留存口径对照**：

| 留存口径 | 保留额 | 一次还本 | 计息余额 | 结清月数 | 总利息 |

**分类**：
- ✅ **已满足的政策约束**：贷款期限不超 30 年（本方案 43 个月）；部分提前还贷须满足保留余额（本方案已扣留存）。
- 🔷 **测算假设**：等额本息；**银行允许无罚金提前还本**（题设条件假设）；公积金留存按题设 7,000 元；固定利率。
- ⚠️ **仍须确认**：留存额实际按 **42,000 元**（6 倍）还是 7,000 元；提前还本是否收取违约金；一次还本的办理时限与所需材料。
