## 阶段 1：资格核验——贷款种类

- 核验：家庭已拥 3 套住宅 → 第 4 套。
- 结果：公积金贷款"认房又认贷、三套及以上拒贷"→ **公积金贷款不可用**。
- 据此确定：只能走**纯商业贷款**（3.0%/年）。公积金仅以"还贷提取 / 月冲"方式用于商贷的提前还本与月供。
- 状态：通过（贷款种类确定）。

## 阶段 2：资金核验——尝试"五年级转学"早期购房路径

- 设想：尽早转学至锡山实验小学，约第 8 个月（2026-08 前后）购房。
- 核验（第 8 个月）：
  - 房价 = 180 万 − 2 万×8 = **1,640,000 元**
  - 现金 = 200,000 + 3,000×8 = **224,000 元**
  - 公积金余额 = 400,000 + 7,000×8 = 456,000 元
  - 首付 15% = 246,000 元；契税 3% = 49,200 元；**首付+税费 = 295,200 元**
  - **295,200 > 224,000 → 现金不足 71,200 元**
- **失效原因**：购房时点过早，现金累积不足，且公积金不能抵首付（"提取还贷 ≠ 抵首付"）。
- **处置**：该路径不成立，放弃五年级转学早期购房方案。下游：转而考察六年级转学与初中对口两条路径。

## 阶段 3：考察"六年级转学"路径（第 20 个月）

- 核验（第 20 个月）：
  - 房价 = 1,400,000 元；现金 = 260,000 元；公积金 = 540,000 元
  - 首付 210,000 + 税费 42,000 = 252,000 ≤ 260,000 → 现金勉强够（余 8,000）
  - 贷款 = 1,190,000 元；可提公积金 533,000 元；提前还本（进取）541,000 元 → 剩余 649,000 元
  - 月还 10,000 元 → 约 **71 个月**、利息约 **60,028 元**
- 状态：现金核验**通过但极紧**（仅余 8,000、零储备）。
- 处置：可行但**显著劣于**初中对口路径（房价高 16 万、利息高约 3.8 万、还清多 28 个月），仅作备选保留。

## 阶段 4：确定"初中对口"路径并核验（第 28 个月，2028-04）

- 时点依据：2028 年 9 月升初一；历年户籍截止约 6-30、信息采集约 5 月中；2028-04 购房可留足过户 + 落户时间（保守截止假设）。
- 核验（第 28 个月）：
  - 房价 = 180 万 − 2 万×28 = **1,240,000 元**
  - 现金 = 200,000 + 3,000×28 = **284,000 元**
  - 公积金 = 400,000 + 7,000×28 = **596,000 元**
  - 首付 15% = 186,000；契税 3% = 37,200；合计 **223,200 ≤ 284,000 → 现金充足（余 60,800）**
  - 贷款 = 1,054,000 元；可提公积金 = 596,000 − 7,000 = 589,000 元
- 状态：**现金与资格核验均通过**。确定为基准方案。

## 阶段 5：基准方案参数与下游传播

确定后**同步更新**全部下游量（价格、首付、税费、余额、月冲、还清年限）：

| 量 | 进取方案 | 稳健方案（留 60,800 储备） |
|---|---|---|
| 提前还本 | 589,000 + 60,800 = **649,800** | 589,000 |
| 剩余本金 | **404,200** | 465,000 |
| 月供能力 | 10,000（月冲 7,000 + 现金 3,000） | 同 |

| 末月还款 | 约 6,647 元 | 约 4,945 元 |

- 下游传播项：
  - **首付/税费**：仅以现金支付 223,200 元；公积金不参与首付。
  - **一次性提前还本**：放款即办理公积金还贷提取 589,000 元 + 结余现金 60,800 元（进取）/仅 589,000 元（稳健）。
  - **月冲**：每月公积金缴存 7,000 元自动冲抵；现金每月补 3,000 元，合计 10,000 元/月。
  - **还清年限**：43 / 50 个月，按"无罚金提前还本"假设成立。
  - **"三年一学位"核查**：购房前必须确认该址 2025-09 至 2028-06 未被他生占用，否则对口入学失效——属购房前必办项，未通过则须换房源并重算。

## 阶段 6：未通过即重算的触发器

| 触发条件 | 影响 | 重算动作 |
|---|---|---|
| 商贷对第 4 套不予放贷 / 首付提至 30% | 现金可能不足 | 追加资金或推迟购房至现金累积达标，重算房价/首付/余额 |
| 公积金提取留存额 >7,000 | 提前还本减少 | 剩余本金↑、利息↑、期限↑ |
| 2028 招生时点提前（如户籍截止提前） | 可等待时点缩短 | 房价升高，重算全部链路 |
| 学位已被占用 | 对口失效 | 换房源，按新房重算 |
| 提前还本有罚金 | 月冲/还本节奏受限 | 重新排期，期限与利息上调 |
