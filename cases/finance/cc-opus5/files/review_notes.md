### 1.3 更早时点是否可行（现金硬约束，与政策无关）

约束式：`(15% + 3%) × (1,800,000 − 20,000m) ≤ 200,000 + 3,000m`
→ `324,000 − 3,600m ≤ 200,000 + 3,000m` → `124,000 ≤ 6,600m` → **m ≥ 18.79 → m ≥ 19（2027-07）**

**复核发现（独立于建议书）**：
- **m=0（今天就买）现金缺 124,000**，即"立刻购房"在算术上就不成立，与入学政策无关。
- **m=8（小学转学窗口）现金缺 71,200**，该路径在资金上亦不成立。
- 因此"等待"不是偏好，而是**被现金约束强制**的。
- 已核对：与 `execution_log.md` §V5、§V7 一致。

### 1.4 更晚时点为何不取

m=29（2028-05）房价 1,220,000、现金余 67,400，纯财务上更优；但 2028 年 5 月中下旬即为材料验证期，**过户＋取证＋落户来不及**。m=36（2028-12，房价 1,080,000）则彻底错过 2028 年小升初。
→ **2028-04 是"跌价规避"与"入学窗口"的交点**，取 m=28 成立。**【须教育行政部门确认】**

### 1.5 更早期限或条件改变时如何重算

> 通用重算式（本节可独立于建议书使用）：
> - 价格 `price(m) = 1,800,000 − 20,000m`（m ≤ 36）
> - 现金 `cash(m) = 200,000 + 3,000m`
> - 公积金 `fund(m) = 400,000 + 7,000m`
> - 可行性 `(δ + τ)·price(m) ≤ cash(m)`，δ＝首付比例、τ＝契税率
> - 最早可负担月 `m* = ⌈((δ+τ)·1,800,000 − 200,000) / ((δ+τ)·20,000 + 3,000)⌉`
> - 贷款 `L = (1−δ)·price(m)`；一次还本 `Q = fund(m) − 留存 + max(cash(m) − (δ+τ)·price(m) − 现金储备, 0)`
> - 还本后余额 `R = L − Q`；还清期数 `n = ⌈−ln(1 − R·r/A) / ln(1+r)⌉`，r＝年利率/12，A＝10,000

| 触发条件 | 重算后的 m* | 结果 |
|---|---|---|
| 首付 20% | 29（2028-05） | ❌ 已过招生窗口 |
| 首付 25% | 36（2028-12） | ❌ 已过窗口且超出跌价期 |
| 首付 30% | 42（2029-06） | ❌ 完全不可行 |
| 招生要求落户满 1 年（须 2027-04 前成交，m=16） | — | ❌ 现金缺 18,400 |
| 跌幅放缓至 1 万/月 | m* 由 19 升至 **26** | 可行窗口被压缩到 m∈[26,28]，几乎无余地 |

## 2. 资金来源的独立重算

### 2.1 三个资金池在 2028-04（m=28）的余额

| 池 | 计算 | 结果 |
|---|---|---|

### 2.2 公积金能否抵首付 —— 独立判定：**不能**

题目已明示"公积金提取用于偿还已有住房贷款不等于可直接抵首付"，检索亦证实无锡两条购房相关提取通道（购房提取、还贷提取）**均以付款／贷款既成为前提**。
→ **首付与契税只能由现金池承担。【政策约束·已满足】**

### 2.3 购房当月资金平衡（逐项重算）

```
首付  = 1,240,000 × 15% = 186,000
契税  = 1,240,000 ×  3% =  37,200
合计现金支出            = 223,200
现金池                  = 284,000
现金结余                =  60,800   ← 与题设"稳健方案保留 60,800"完全吻合
商业贷款 = 1,240,000 × 85%          = 1,054,000
```

**恒等式校验（全部通过）**
- `186,000 + 1,054,000 = 1,240,000` ✅（首付 ＋ 贷款 ＝ 房价）
- `186,000 + 37,200 + 60,800 = 284,000` ✅（现金去向闭合）
- `596,000 − 7,000 + 60,800 = 649,800` ✅（方案 A 一次还本）
- `1,054,000 − 649,800 = 404,200` ✅（方案 A 还本后余额）
- `1,054,000 − 589,000 = 465,000` ✅（方案 B 还本后余额）

### 2.4 "60,800 从何而来"的独立验证

`cash(28) − 0.18 × price(28) = (200,000 + 84,000) − 0.18 × 1,240,000 = 284,000 − 223,200 = 60,800`
→ 题设给出的 60,800 **不是外生数字，而是 m=28、δ=15%、τ=3% 下的唯一解**。这反向确认了三个情景参数与 28 个月互相自洽。**【已核对】**

### 2.5 前期累积与月度偿债能力**未重复计算**的验证

- 购房**前**：现金 3,000/月 与公积金 7,000/月 **分账累积**，分别进入 284,000 与 596,000，已在 §2.1 一次性计入。
- 购房**后**：每月偿债能力 10,000 ＝ 当期新增公积金 7,000（经月冲）＋ 当期新增现金 3,000，**全部是购房后才产生的现金流**。
- 两者时间上不重叠，**无重复计算**。✅

## 4. 还清期限的独立重算

闭式解：`n = ⌈ −ln(1 − R·r / A) / ln(1+r) ⌉`，r = 0.0025，A = 10,000

**方案 A：R = 404,200**
```
R·r / A = 404,200 × 0.0025 / 10,000 = 0.101050
1 − 0.101050 = 0.898950
−ln(0.898950) = 0.1065279
ln(1.0025)    = 0.0024968828
n = 0.1065279 / 0.0024968828 = 42.664 → ⌈⌉ = 43
```
**方案 B：R = 465,000**
```
R·r / A = 465,000 × 0.0025 / 10,000 = 0.116250
1 − 0.116250 = 0.883750
−ln(0.883750) = 0.1235806
n = 0.1235806 / 0.0024968828 = 49.494 → ⌈⌉ = 50
```

**逐期 Decimal 摊销表复算（独立方法，分为单位四舍五入）**

| | 方案 A | 方案 B |
|---|---|---|
| 还本后余额 | 404,200.00 | 465,000.00 |
| 第 1 期末余额 | 395,210.50 | 456,162.50 |
| 第 12 期末余额 | 294,830.32 | 357,479.61 |
| 第 24 期末余额 | 182,134.04 | 246,688.86 |
| 第 36 期末余额 | 66,010.00 | 132,528.30 |
| 第 42 期末余额 | 6,630.11 | 74,152.44 |
