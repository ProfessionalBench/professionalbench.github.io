## E2 初始判断（读材料时的第一版思路）

**初始思路（后被修正）**：以「一月余前 HbA1c 14.6%、空腹血糖 21.7 mmol/L、尿酮 +」为起点，
按「糖尿病 + 酮症 + 多尿」三线并行：① 急症排查；② 分型；③ 多尿病因（尿崩症方向）。
体重下降 5 kg 与多饮多尿 3 年余初判倾向于「长期未控制糖尿病 + 渗透性利尿」。

**随即发现的两个问题**：
1. 02 的「尿酮 +」是**一月余前的外院人工转录**，且**当时未查血气、无血 β-羟丁酸**；
   用它推断「本次存在酮症」属跨样本外推。
2. 03 的「无明确酸中毒的糖尿病」是在**血气与血酮未回报**时写下的，且**无主治医师审核签名**；
   它把「尚未排除酸中毒」表述成了「无酸中毒」。

**落点**：事实基线表的效力列；1.3 诊断层级表 L1 行；第五部分冲突表第 1、4 行。

## E3 关键冲突（逐条登记）

### 冲突 1：外院人工转录 vs 本次入院当前样本（效力冲突，最高优先）

| 项 | 内容 |
|---|---|
| 冲突 | 02 记「尿酮 +」「尿糖 4+」（一月余前，人工转录，无条码/无采样时间）；01 与 03 均明确本次当前样本（血气、血 β-羟丁酸、电解质、血渗透压、尿量）未回报 |
| 依据 | M4 资料使用 1：外院人工转录可用于说明病程，但不能替代当前危象判定；M4 资料使用 3：未返回的结果只能列「待查」 |
| 处理 | 本次酮症判定改以**本次入院当前样本定量血 β-羟丁酸（A3）+ 本次尿酮（A8）**为准；外院结果降级为「病程说明」 |
| 落点 | 1.1（A3、A8 备注列）；1.3 L1 行；第七部分第 1 条；source_note 2.2 |

### 冲突 2：交班摘要「无明确酸中毒」vs 酸中毒尚未排除（逻辑冲突）

| 项 | 内容 |
|---|---|
| 冲突 | 03 写「暂拟按『无明确酸中毒的糖尿病』安排」，但其自身声明血气与血酮未回报 |
| 依据 | M4 资料使用 2：摘要形成后回报的新结果与摘要冲突时应采用新结果；M4 检查时序 1：应先完成血糖、血酮、酸碱、电解质、肾功能与渗透状态评估 |
| 处理 | 改为「疑似急性高血糖危象（DKA 和/或 HHS），待第一批结果确认」；在结果回报前不下达危象诊断 |
| 落点 | 1.1 第一批 A1–A9；1.3 L1 行；第五部分第 1 行；第七部分第 4 条 |

### 冲突 3：交班摘要「先做尿崩症动态试验」vs 检查安全规则（安全冲突，最关键）

| 项 | 内容 |
|---|---|
| 冲突 | 03 建议「如床位周转紧张，可先完成尿崩症相关动态试验再等其他结果」 |
| 依据 | M4 检查时序 2：限水、禁水或高渗刺激类操作，只有在急性代谢紊乱已纠正并由专科监护时才可进入执行阶段；此外高血糖未纠正时结果被渗透性利尿混杂，无判读价值 |
| 处理 | **不执行**。阶段 0 仅做定量记录（24 h 尿量、尿渗透压、出入量、体重）；动态试验推迟至阶段 2/3，并须逐项满足 3.4 全部安全前提（含时序、血糖、电解质、容量、肾功能、知情同意与可监护性、终止标准） |
| 落点 | 3.1 阶段 0/1/2/3 表；3.4 安全前提表（含「禁止事项」行）；第五部分第 2 行；第七部分第 3 条 |

### 冲突 4：交班摘要「常规分型 + 并发症 + 多尿病因」并排 vs 时序与适应证要求

| 项 | 内容 |
|---|---|
| 冲突 | 03 将三类检查并列安排，未区分急性期/稳定期，也未区分常规筛查与需适应证项目 |
| 依据 | M4 检查时序 1（先急症评估再定病因学检查时序）；instruction 第 2 问要求区分常规床旁筛查与有适应证才做 |
| 处理 | 分型与并发症评估整体推迟至急性代谢紊乱纠正后 24–72 h 起；全部检查表增设「类别」列，标注「常规床旁」或「有适应证才做」 |
| 落点 | 第二部分 2.1（B1–B8）、2.2、2.3、2.4；第六部分时序总表 |

### 冲突 5：马凡样体征与晶状体脱位在全部材料中均无评估路径

| 项 | 内容 |
|---|---|
| 冲突 | 01 查体已记录拇指征/腕征阳性、臂展 171 cm、上部量 80 cm/下部量 86 cm、脊柱可疑侧弯、拇外翻，既往晶状体脱位 1 年；但 03 交班摘要未提及任何评估安排 |
| 依据 | 01 查体记录本身；M4 检查时序 3（辐射前妊娠核实） |
| 处理 | 新增第四部分：4.1 线索整理、4.2 常规 vs 有适应证项目（经胸心脏超声优先）、4.3 与多尿路径的交叉提示、4.4 妊娠核实流程 |
| 落点 | 第四部分全部；第六部分第 7 行 |

### 冲突 6：育龄 + 月经不规律 + 末次月经 2022-09-25 vs 无妊娠核实安排

| 项 | 内容 |
|---|---|
| 冲突 | 01 记「月经不规律，周期约 1–2 月」「末次月经 2022-09-25」；02 未记妊娠状态；03 未提及妊娠核实；而计划中可能涉及 CT 等电离辐射检查 |
| 依据 | M4 检查时序 3：对月经不规律且妊娠状态未核实的育龄患者，非急诊电离辐射影像前应先记录妊娠状态并据此决定实施或延期 |
| 处理 | 妊娠试验（血/尿 β-hCG）列为**入院常规项**（非电离辐射、无禁忌）；4.4 设六步流程（核实—记录—妊娠阳性分流—妊娠阴性分流—无法确定按可能妊娠处理—急救例外） |
| 落点 | 1.2 触发条件表妊娠试验行；4.4 全表；第六部分第 1、7 行；结论汇总第 6 条 |

### 冲突 7：病史时间线的内在张力（3 年多尿 vs 1 月余高血糖）

| 项 | 内容 |
|---|---|
| 冲突 | 多饮多尿始于 3 年余前，而明确高血糖仅见于 1 月余前；三年间饮水量与排尿次数均为自述、**从未定量**（01 明确「未记录 24 小时尿量」）。1 年前空腹血糖 5.7、HbA1c 6.3% 尚不支持显著高血糖 |
| 处理 | 不预设「多年多尿一直由渗透性利尿解释」，也不预设尿崩症。改为**用阶段 1 的观察来回答**：血糖达标且稳定后多饮多尿是否缓解 → 缓解则结论为渗透性利尿，持续则进入阶段 2 低渗性多尿确认 |
| 落点 | 3.1 阶段 1 触发条件；3.2 关键时序判断段；结论汇总第 3 条 |

## E6 同步更新义务（本日志自身的边界）

本日志记录的是**过程**，不是结论的存放处。依据 M4「正式结论边界」第 2 条：
若本次入院回报的新检验结果改变了检查路径或诊断判断，**必须同步更新
`内分泌专科入院评估.docx` 正文与 `source_note.md` 的结论边界**，
不得只在 `execution_log.md` 中保留新结论。

**若发生以下任一情形，需回改的章节**（预登记，便于触发时执行）：
- 血气/血酮/渗透压回报 → 1.3（L0/L1 层级、危象分类）与结论汇总第 1 条；
- 血 β-hCG 回报 → 1.2、4.4、结论汇总第 6 条；
- C 肽与抗体回报 → 2.1、结论汇总第 2 条；
- 心脏超声/基因回报 → 4.2、结论汇总第 4 条；
- 24 h 尿量与尿渗透压定量回报 → 3.1 阶段 0/2、结论汇总第 3 条。
