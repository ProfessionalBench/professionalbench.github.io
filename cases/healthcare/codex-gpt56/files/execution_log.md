## 4. 方案调整与触发条件

1. 先行急症评估：床旁血糖/生命体征/意识与容量状态，同时送当前静脉血气、β-羟丁酸、电解质、肾功能、实测血浆渗透压等；按结果识别 DKA、HHS或重叠。
2. 诱因检查由症状和体征触发，避免无指征的全套培养、胸片、脂肪酶或心肌标志物；育龄患者同步核实妊娠可影响治疗与影像选择。
3. 急性代谢稳定后完成糖尿病分型：胰岛自身抗体先采，配对血糖的 C 肽在糖毒性/酮症纠正后解释；外源胰岛素后胰岛素自身抗体解释受限。
4. 多尿路径先量后分：24 h 尿量或严格出入量确认客观多尿；高血糖/尿糖时先考虑渗透性利尿；血糖稳定后若尿量仍超过 3 L/d 或约 50 mL/kg/d（本例体重换算约 3.84 L/d）且尿渗透压 <300 mOsm/kg，才进入 AVP 缺乏、肾性尿崩症、原发性烦渴路径。
5. 马凡评估优先眼科裂隙灯及超声心动图；全主动脉影像优先无电离辐射方案。CT/放射检查若非急诊，先核实妊娠；若疑急性主动脉综合征则按急救风险权衡，不因等待而不当延误。
