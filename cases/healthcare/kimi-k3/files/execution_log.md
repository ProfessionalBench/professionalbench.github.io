## 1. 材料核对（逐一读取并提取）

- **材料01《入院病史与查体.pdf》**：提取主诉/现病史（3年前服药后多饮多尿→2年前加重→1年前血糖正常高值→1月余前外院高血糖→3天前起始诺和佳未监测→近1月体重降5 kg）、既往史、月经婚育家族史、查体全套数值。注意到材料自述“不含本次入院当前血气、血酮、电解质、血渗透压或定量尿量结果”。→ 落点：docx第一节A级、各阶段病史引用。
- **材料02《外院检验转录与门诊交接.xlsx》**：三个时点（一年前/一月余前/三日前）数值与“人工转录、无原始条码、不替代本次入院样本或危象判定”的使用边界。注意到一月余前“尿酮+”当时未查血气、无血β-羟丁酸。→ 落点：docx第一节B级（仅作病程支持）、第五节（不列入既成事实）。
- **材料03《床旁交班摘要.pdf》**：当日07:40、未审核签名；本院血气、血β-羟丁酸、电解质、血渗透压、定量尿量尚未回报；含两条处置提议。→ 落点：docx封面资料依据、第六节边界声明。
- **材料04《病历资料与检查安全规则.pdf》**：资料使用3条、检查时序与安全3条、结论边界2条，作为全流程硬约束。→ 落点：docx各阶段触发条件与安全前提。

## 2. 初始判断

- 糖尿病高度可能但未经本次样本确认：典型症状＋体重下降＋外院转录显著高血糖（FPG 21.7 / 2hPG 30.6 / HbA1c 14.6%），转录效力受限 → 诊断层级定为“待确认（分型未定）”。→ docx第一节B级。
- 外院尿酮+＋近1月体重下降＋胰岛素起始3天未监测 → 当前必须按“高血糖危象待排除”处理，第一层检查先行。→ docx第二节（第一阶段）。
- 多饮多尿先于高血糖至少2年（1年前HbA1c 6.3%时多尿已存在）→ 糖尿病不能解释全部多尿病程，多尿需独立分阶段评估。→ docx第四节“时序要点”。
- 晶状体脱位＋拇指征/腕征阳性＋脊柱可疑侧弯＋臂展＞身高 → 马凡样体征，按Ghent框架评估而非直接诊断。→ docx第四节第2部分。

## 4. 方案调整（相对交班原计划）

1. **时序调整**：交班方案“常规分型＋并发症＋多尿病因检查并行、可先做动态试验” → 调整为三阶段串行：当前急症排查（第一阶段）→ 病情稳定后分型/并发症/甲状腺/生殖代谢（第二阶段）→ 多尿分阶段鉴别与马凡评估（第三阶段）。→ docx整体结构。
2. **检查前置**：血hCG由“生殖评估时再查”提前至第一阶段（育龄＋月经不规律＋妊娠状态未核实，决定后续影像路径）。→ docx第二节、第四节第3部分。
3. **动态试验安全化**：补充安全前提（代谢纠正、血流动力学稳定、基线血钠正常、专科监护、终止标准、风险告知）。→ docx第四节安全前提清单。
4. **马凡路径无辐射优先**：首选超声心动图与眼科会诊；CTA列为有适应证才做且须走妊娠核实流程，MRA优先。→ docx第四节第2部分。
5. **鉴别扩展**：晶状体脱位＋马凡样体型 → 增加血同型半胱氨酸（排除同型半胱氨酸尿症）为有适应证检查；多尿若确认AVP缺乏且分型不典型 → 视神经/听力评估（Wolfram谱系）列入适应证检查。→ docx第四节第2部分、第三节并发症表。
