- “待分型”“疑似”“需要排除”不等于确诊；路径或判断改变时主体报告与记录同步更新。

## 2. 判断标准来源说明

DKA/HHS判读阈值（血糖≥11.1 mmol/L、血β-羟丁酸≥3.0 mmol/L、pH＜7.30、HCO₃⁻＜18 mmol/L、有效渗透压≥320 mOsm/kg等）、
多尿分阶段鉴别流程（24小时尿量＞3 L、尿渗300 mOsm/kg界值、禁水-加压素试验与高渗盐水刺激的安全前提）、
Ghent 2010马凡评估框架及系统评分计分，均引自通用公开专业标准，仅用于解释判断标准，不构成新患者事实；
最终判定以本院回报及专科判断为准。

## 3. 关键冲突与处理

- **交班摘要 vs 安全规则**：交班提议“可先完成尿崩症动态试验再等其他结果”，违反材料04“急性代谢紊乱纠正前不得进入限水/禁水/高渗刺激类操作”；且“无明确酸中毒”系据外院转录尿酮+推断，非本次样本。处理：不采纳，动态试验列为第三阶段且设安全前提。
- **外院转录 vs 当前样本**：一月余前尿酮+不能推断当前酸中毒状态；当前危象判定只能等待本次入院样本。
- **LMP绝对日期（2022-09-25）**：与全文相对时点并存，且月经长期不规律，不据日期豁免妊娠核实，以本次血hCG为准。

## 4. 结论边界

1. 糖尿病：写“待本次入院样本确认（分型未定）”；外院转录仅作病程支持。
2. DKA、HHS、脱水、电解质紊乱、诱因、妊娠：结果未回报前一律“待排除/待评估/待核实”。
3. 多尿病因、糖尿病分型、马凡综合征：未定，不预判；当前仅“马凡样体征”。
4. 待查清单（docx第五节）内项目一律不得写成既成事实；任何新回报改变路径时主体报告同步更新。
