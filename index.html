Preserve the whole workflow.

A professional outcome depends on the judgments, actions, and checks that produce it. Each responsibility must remain with the agent.

Cover the work.

More tasks do not automatically mean better coverage. We organize professional units and workflows across finance, law, and healthcare, then build tasks to cover that space.

Preserve the work.

If a task supplies the judgment, the execution plan, or the final verification, those responsibilities go untested. We call this Workflow Compression—and build tasks that preserve the work the role should do independently.

Consider a tax return review.

Which records are valid? How should the return be corrected? Has every change been checked? Supplying these answers changes what an agent must do—and what its score can tell us.

K

Know

Make the judgment.

Assess the evidence and decide what applies. In a tax review, distinguish current records from superseded sources.

A

Act

Do the work.

Plan, execute, and adapt. Correct the return using the right evidence and handle the consequences of each change.

C

Close

Verify the outcome.

Check the result, resolve discrepancies, and leave traceable evidence that the work is complete.

These responsibilities depend on one another. A polished deliverable can still rest on the wrong evidence—or hide a problem that was never checked.
